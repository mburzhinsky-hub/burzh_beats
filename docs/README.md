# BURZH beats — iPhone web test

This directory is an isolated PWA test build for iPhone/Safari and GitHub Pages.

The Android application remains in `/app` and is not replaced by this web build.

Web test scope:
- responsive BURZH beats UI
- Settings / Favorites UI
- WeatherAPI widget
- foreground browser geolocation for Locator
- Add to Home Screen / standalone PWA

Android-only in this build:
- full Yandex Music playback/auth flow
- Android MediaSession / lock-screen controls
- native DSP
- Android haptics
