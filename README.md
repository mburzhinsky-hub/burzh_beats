# BURZH beats

Минималистичное радио по жанрам: Future Garage, Lo-Fi, Deep House, Trance.
Монохромный дот-матричный интерфейс, альбомный «экранчик» для рабочего стола, музыка — только твоя.

**Веб-версия (iPhone, iPad, десктоп):** https://mburzhinsky-hub.github.io/burzh_beats/
Открой в Safari → «Поделиться» → «На экран Домой».

## Как работает эфир

Каждая станция — это плейлист из миксов, который крутится по общим часам. Нажимаешь play и
попадаешь туда, где эфир идёт *сейчас*, как на настоящем радио: на всех устройствах в одну
секунду играет одно и то же. Пауза = выключить радио, следующее включение — снова в живой эфир.

- Порядок миксов перемешивается на каждом круге (детерминированно, одинаково у всех).
- Если к миксу приложен треклист, на экране, на экране блокировки и в StandBy виден реальный
  трек внутри микса.
- Переключение станций — плитки, свайп по обложке, кнопки ⏮ ⏭, кнопки на экране блокировки.
- Станция без миксов показывает `OFF AIR`.

Почему часовые миксы, а не отдельные треки: на iPhone веб-плееру нельзя менять громкость,
поэтому плавные переходы между треками возможны только через Web Audio, а он ломает фоновое
воспроизведение. Сведённый микс — бесшовный звук и стабильная работа на заблокированном экране.

## Альбомный экран («экранчик»)

- Огромные часы Doto, дата, погода, станция и трек; справа большая планета.
- Планета — вращающийся шар из точек. У каждой станции на нём свой «передатчик»: при смене
  станции планета делает оборот и разворачивается к нужному. Комета на орбите и свечение
  реагируют на музыку (на реальные низы, когда включена обработка звука).
- Через 8 секунд без касаний кнопки уходят, остаются часы, планета, шкала станций и прогресс;
  первое касание только будит экран.
- Экран не гаснет в альбомной ориентации (Screen Wake Lock, iOS 18.4+).
- Ночной режим: та же палитра, только приглушённая. По умолчанию выключен; AUTO — с 23:00 до 7:00.
- Защита OLED от выгорания: раз в минуту картинка смещается на несколько пикселей.
- Погода: Open-Meteo, по запросу геопозиции (Настройки → Экран → Weather). Координаты хранятся
  только в браузере, округлённые до ~1 км.

**StandBy на iPhone.** Свой интерфейс в системный StandBy веб-приложение встроить не может —
туда попадают только виджеты нативных приложений. Когда играет радио и телефон заблокирован,
StandBy и экран блокировки показывают системную карточку «Сейчас играет» с обложкой станции
(`docs/art/*.png`), названием трека и кнопками переключения станций.
Хочешь именно свой экранчик — оставь приложение открытым в альбомной ориентации на зарядке.

## Звук

Настройки → Sound → **Sound shaping**. Цепочка Web Audio:

```
вход → trim → rumble-фильтр → 6-полосный EQ ─┬─ сухой сигнал
                                              ├─ бас-энхансер (гармоники саба)
                                              └─ clarity (гармонический «воздух»)
  → ширина стерео (mid/side, только выше 150 Гц) → glue-компрессор → level → лимитер
```

- Пресеты: Auto (по станции: Club для Trance, Deep для Deep House, Warm для Lo-Fi, Wide для
  Future Garage), Flat, Club, Deep, Warm, Wide, Clear, Night и твой Custom.
- Эквалайзер рисуется живой кривой поверх спектра: тяни точки, двойной тап сбрасывает полосу.
- Автоматический запас по уровню: подъём EQ компенсируется на входе, лимитер ловит остатки.
- Обработка по умолчанию **выключена**. При первом включении воспроизведение один раз
  переключается на элемент, подключённый к цепочке; дальше «выкл» — нейтральный обход внутри
  цепочки, музыка не прерывается. После перезапуска приложения с выключенной обработкой снова
  работает обычный `<audio>`.
- Страховка: если цепочка молчит или не стартует (проверяется 6 секунд после запуска), приложение
  само возвращается на обычный звук и сообщает об этом. Состояние движка видно в Настройки → About.
- На iPhone веб-аудио при блокировке экрана может остановиться — проверь на своём телефоне.
- Нужны аудиофайлы с того же домена или с CORS (для внешнего хранилища добавь
  `Access-Control-Allow-Origin`). Иначе приложение само отключит обработку и продолжит играть.
- Какой пресет у станции — поле `"sound"` в `docs/stations.json`.

## Добавить музыку

Нужен `ffmpeg` (`brew install ffmpeg`).

```bash
python3 tools/radio.py build          # первый запуск создаст папки library/<станция>/
# положи файлы: library/lofi/night-tape-01.mp3 (+ night-tape-01.txt с треклистом, по желанию)
python3 tools/radio.py build          # перекодирует и обновит docs/stations.json
python3 tools/radio.py list           # что сейчас на станциях
git add docs && git commit -m "Add Lo-Fi mixes" && git push
```

`build` делает для каждого файла:
- выравнивание громкости до −14 LUFS (двухпроходный EBU R128) — все станции звучат одинаково;
- AAC 128 kbps `.m4a` с faststart — мгновенный старт и перемотка;
- название и артист берутся из тегов файла или из имени;
- треклист из `.txt` (строки вида `00:00 Artist - Title` или `1:02:33 Title`) или `.cue`.

Папка `library/` в git не попадает. Уже перекодированные файлы повторно не обрабатываются.
Старые миксы остаются в станции; `--prune` удаляет те, которых больше нет в `library/`.

### Хранение аудио вне git

Сейчас миксы лежат в `docs/media/` и раздаются GitHub Pages. Для большой библиотеки лучше
внешнее хранилище (например, Cloudflare R2 с публичным доменом):

```bash
python3 tools/radio.py build --out dist-media --media-base https://media.example.com/burzh/
# загрузи dist-media/ и текущие docs/media/* в хранилище, затем удали docs/media из репозитория
```

Можно также добавить станцию-поток: вместо `items` укажи `"stream": "https://…/stream.mp3"`.

### Новая станция

Добавь объект в `docs/stations.json` (`id`, `name`, `glyph`: `grid|wave|rings|tri`, `accent`,
`tempo` — период орбиты в секундах, `sound` — пресет звука, `tagline`, `art`) и выполни `python3 tools/make_art.py`,
чтобы нарисовать обложку. Плитки и меню жанров строятся из `stations.json` автоматически.

## Структура

```
docs/                 веб-радио (GitHub Pages)
  index.html          разметка и стили
  app.js              движок эфира, интерфейс, настройки, погода
  planet.js           планета на canvas
  sound.js            звуковая цепочка и пресеты
  sound-ui.js         эквалайзер: кривая, спектр, перетаскивание
  stations.json       станции и миксы
  sw.js               офлайн-оболочка (аудио не кэшируется)
  art/                обложки станций для экрана блокировки / StandBy
  fonts/              Doto и IBM Plex Mono (OFL), без внешних запросов
  media/              аудио
app/                  Android: нативная оболочка вокруг того же веб-радио
tools/radio.py        сборка библиотеки и проверка (validate)
tools/make_art.py     иконки приложения и обложки станций
```

## Android

Приложение в `app/` — тонкая оболочка (WebView) над той же веб-версией: одни станции, один эфир.
Нативная часть добавляет вибро-отклик и удержание экрана для альбомного режима; переходы на
чужие сайты открываются в браузере. Каждый пуш с изменениями в `app/` собирает debug APK
(GitHub Actions → артефакт `BURZH-beats-debug-apk`).

## Проверки

`python3 tools/radio.py validate` проверяет `stations.json`, наличие аудио, размеры и целостность
иконок и обложек. Запускается в CI на каждый PR (`.github/workflows/check-web.yml`).

Иконки перерисовываются командой `python3 tools/make_art.py`.
